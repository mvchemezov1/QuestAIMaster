## О программе

**Text Quest AI** — десктопное приложение для Windows, macOS и Linux, которое превращает любую вашу идею в интерактивный текстовый квест с ИИ-гейммастером. Вы задаёте жанр, сеттинг, героя и завязку — нейросеть ведёт повествование, реагирует на ваши действия, отслеживает инвентарь, квесты, локации и отношения с NPC.

Программа написана на **Python + Tkinter**, работает с несколькими провайдерами ИИ (как облачными, так и локальными) и **не требует интернета** при использовании Ollama.

> **Ключевая идея:** вы не пишете код и не редактируете JSON — вы просто играете. Всё остальное (память сюжета, карточки предметов, карта мира, броски кубика) ИИ ведёт сам через специальные теги в ответе, а программа их автоматически разбирает.

## Возможности

### Основное
- 🎭 **ИИ-гейммастер** ведёт повествование от второго или третьего лица, помнит контекст, реагирует на действия и предлагает варианты дальше.
- 🔌 **6 текстовых провайдеров** на выбор: GigaChat, YandexGPT, OpenRouter, DeepSeek, Ollama (локально) и любой свой OpenAI-совместимый сервер.
- 🎤 **Голосовой ввод** через SpeechRecognition — можно говорить действие вместо набора с клавиатуры.
- 🔊 **Озвучка** через pyttsx3 — программа читает ответы ИИ вслух, есть автоозвучка.
- 🌐 **Мультиплеер по сети** — хост запускает сервер, остальные подключаются по IP. Роли: ведущий, игрок, наблюдатель.
- 🛡️ **Полностью офлайн-режим** через Ollama — никакие данные не уходят в интернет.

### Игровые механики
- 🎲 **RPG-режим** с характеристиками (сила, ловкость, интеллект, харизма, здоровье, мана) и бросками d20 против сложности.
- 🃏 **Карточки предметов и существ** — создаются автоматически, хранят описание, свойства, статус, HP, отношение, локацию, характер и цель.
- 🎒 **Инвентарь и экипировка** — 10 слотов (голова, шея, тело, руки, ноги, обувь, пояс, оружие, щит, кольцо). Бонусы от экипировки учитываются в характеристиках и бросках.
- 📜 **Журнал квестов** со статусами: активен, выполнен, провален.
- 🗺️ **Карта мира** — граф локаций с силовым layout, посещённые и не посещённые точки.
- 🧠 **Редактируемая память сюжета** — список «важных фактов», которые считаются каноном.
- 🕵️ **Приватные действия** в мультиплеере — если игрок действует скрытно, ИИ отвечает только ему.

### UX и удобство
- 💾 **Пресеты историй** — сохраняйте любимые настройки и загружайте в один клик.
- 🎨 **Стилевые пресеты** — «Мрачное фэнтези», «Героическое фэнтези», «Юмор и пародия», «Нуар», «Лавкрафтианский ужас», «Уютное приключение».
- 🚦 **Модерация контента** — три режима: без ограничений, мягкая, жёсткая.
- ⚙️ **Профили генерации** — «Точно/Канон», «Сбалансированно», «Творчески», плюс ручные ползунки.
- ↩️ **Undo/Redo ходов** (`Ctrl+Z`, `Ctrl+Y`) — откат до 20 ходов назад.
- 🌿 **Ветки** — сохраняйте состояние и возвращайтесь к нему позже.
- 🔄 **Регенерация последнего ответа** (`Ctrl+R`).
- 💽 **Автосохранение** каждые 5 ходов и при закрытии окна.
- 📖 **Экспорт книги** в Markdown и PDF.
- 🌑 **Тёмная тема**.
- 📜 **История ввода** — стрелками вверх/вниз листайте прошлые действия.
- 🧩 **Плагины** — папка `~/.quest_ai/mods/`, любой `.py` с `register(api)`.
- 📊 **Журнал ошибок** и **статистика сессии**.

## Установка

### Вариант 1. Готовый установщик (Windows)

1. Скачайте `QuestAI_Setup.exe` из раздела релизов.
2. Запустите установщик. Windows SmartScreen может показать предупреждение — нажмите **«Подробнее» → «Выполнить в любом случае»**.
3. Выберите папку установки (по умолчанию `C:\Program Files\Quest AI`).
4. Отметьте галочку «Создать ярлык на рабочем столе», если хотите.
5. Нажмите **«Установить»**.

**Удаление:** Панель управления → Программы и компоненты → Quest AI → Удалить. Пользовательские данные в `C:\Users\Ваше_Имя\.quest_ai` **не удаляются** — сохранения останутся.

### Вариант 2. Запуск из исходников

1. Установите Python 3.9+ с [python.org](https://www.python.org/downloads/). На Windows обязательно отметьте **«Add Python to PATH»**.
2. Скачайте `quest_ai.py` в удобную папку.
3. Откройте терминал и перейдите в эту папку:

   ```bash
   cd путь/к/папке
   ```

4. Установите обязательные зависимости:

   ```bash
   pip install gigachat
   ```

   > Это нужно только если планируете использовать GigaChat. Для остальных провайдеров дополнительных пакетов не требуется.

5. Опциональные зависимости:

   ```bash
   pip install pyttsx3 SpeechRecognition pyaudio reportlab keyring
   ```

   | Пакет | Для чего |
   |-------|----------|
   | `pyttsx3` | Озвучка ответов ИИ |
   | `SpeechRecognition` + `pyaudio` | Голосовой ввод |
   | `reportlab` | Экспорт книги в PDF |
   | `keyring` | Безопасное хранение API-ключей в системном хранилище |

6. Запустите:

   ```bash
   python quest_ai.py
   ```

### Вариант 3. Сборка EXE из исходников

1. Установите PyInstaller:

   ```bash
   pip install pyinstaller
   ```

2. Перейдите в папку с `quest_ai.py` и выполните:

   ```bash
   pyinstaller --onefile --windowed --name="QuestAI" quest_ai.py
   ```

3. Через минуту в папке `dist/` появится `QuestAI.exe`.

### Вариант 4. Сборка установщика из EXE

См. пример скрипта для **Inno Setup**:


## Быстрый старт

1. Запустите программу. Появится окно выбора режима:
   - **одиночная игра**
   - **создать сетевую игру (хост)**
   - **подключиться к сетевой игре**
2. Выберите **одиночная игра**.
3. Заполните настройки истории:
   - **Название истории** — например, «Проклятие Драконьего перевала».
   - **Жанр/тон** — «тёмное фэнтези», «киберпанк», «детектив».
   - **Мир и сеттинг** — где происходит действие.
   - **Завязка сюжета** — с чего начинается история.
   - **Имя героя** и **описание героя**.
   - **Стиль повествования** — можно нажать один из шести стилевых пресетов.
4. Выберите **провайдера ИИ** внизу окна.
5. Введите API-ключ (если требуется) — по одному на строку.
6. Настройте параметры генерации: temperature, top-p, max_tokens, длину хода.
7. Включите **RPG-режим**, если хотите характеристики и броски кубика.
8. Нажмите **«Начать историю»**.

## Настройка провайдеров ИИ

Все настройки — в окне **«Настроить историю…»** в блоке **«Провайдер текста»**.

### GigaChat (Сбер)

- ✅ **Бесплатный тариф Freemium** с лимитом запросов.
- 🔗 Регистрация: <https://developers.sber.ru/studio>
- 🔑 Пул ключей: **Authorization Key** либо пара `client_id:client_secret`.
- 🤖 Модель: `GigaChat-2`.
- 📦 Требуется `pip install gigachat`.

### YandexGPT

- 🎁 **Стартовый грант** при регистрации в Yandex Cloud.
- 🔗 Регистрация: <https://yandex.cloud/ru/docs/ai-studio/>
- 🔑 Пул ключей: строки в формате `API_KEY:FOLDER_ID`.
- 🤖 Модели: `yandexgpt-lite`, `yandexgpt`.

### OpenRouter

- 🌍 Доступ к GPT-4o, Claude 3.5, Llama 3.1 и другим через **один ключ**.
- 🔗 Регистрация: <https://openrouter.ai/keys>
- 🔑 Ключ формата `sk-or-v1-...`.
- 🤖 Модель: `openai/gpt-4o-mini`, `anthropic/claude-3.5-sonnet`, `meta-llama/llama-3.1-70b-instruct`.
- 🌐 Base URL: `https://openrouter.ai/api/v1`.

### DeepSeek

- 💰 **Дешёвый и быстрый** OpenAI-совместимый API.
- 🔗 Регистрация: <https://platform.deepseek.com/api_keys>
- 🤖 Модели: `deepseek-chat`, `deepseek-reasoner`.
- 🌐 Base URL: `https://api.deepseek.com/v1`.

### Ollama (локально)

- 🔒 **Полностью офлайн**, никакие данные не покидают компьютер.
- 🔗 Скачать: <https://ollama.com/download>
- 🚀 Запуск: `ollama serve`, затем `ollama pull llama3.1`.
- 🔑 Ключ не нужен.
- 🌐 Base URL: `http://localhost:11434/v1`.

### Custom (свой сервер)

Любой OpenAI-совместимый сервер: LM Studio, vLLM, text-generation-webui, llama.cpp server. Укажите Base URL, модель и, если нужно, ключ.

### Пул ключей с автопереключением

В поле пула можно ввести **несколько ключей** — по одному на строку. При ошибке `429`, `403`, `quota`, `insufficient` программа **автоматически переключится на следующий**. Это позволяет обходить дневные лимиты Freemium.

### Безопасное хранение ключей

Если установлена библиотека `keyring`, пул сохраняется в системное хранилище:

| ОС | Хранилище |
|----|-----------|
| Windows | Credential Manager |
| macOS | Keychain |
| Linux | Secret Service |

Без `keyring` — в JSON-файл `~/.quest_ai/app_settings.json` в открытом виде. **Не публикуйте этот файл.**

## Как играть

### Основное окно

- Верхняя часть — текст повествования с Markdown-форматированием.
- Ниже — панель чата, кнопки действий и поле ввода.
- Самая нижняя строка — статус и статистика.

### Действия

| Способ | Как |
|--------|-----|
| **Кнопки ИИ** | Клик по одной из 2-4 кнопок под ответом |
| **Свои кнопки** | «+ Добавить свою кнопку» |
| **Поле ввода** | Написать и нажать Enter |
| **Приватно** | Галочка рядом с полем ввода |

### Горячие клавиши

| Клавиши | Действие |
|---------|----------|

| `Ctrl+S` | Быстрое сохранение |

## RPG-режим

Когда включён, ИИ не решает исход рискованных действий сам — он запрашивает проверку:

```
[ROLL]сила|15|Атака по гоблину[/ROLL]
```

| Поле | Описание |
|------|----------|
| **Характеристика** | `сила`, `ловкость`, `интеллект`, `харизма`, `здоровье`, `мана` |
| **Сложность (DC)** | 8 — просто, 12 — средне, 16 — трудно, 20 — почти невозможно |
| **Метка** | Необязательное описание проверки |

Программа:

1. Бросает d20.
2. Прибавляет характеристику **с учётом бонусов от экипировки**.
3. Сравнивает с DC.
4. Отправляет результат ИИ.
5. ИИ описывает последствия.

⚠️ Защита от зацикливания: не более 3 последовательных бросков без действия игрока.

Бонусы от экипировки считаются автоматически: если у меча в свойствах `"сила": "+2"` — прибавится к силе.

## Мультиплеер

### Запуск сервера

1. Меню **Сетевая игра → Создать игру (хост)…**
2. Введите имя, порт (по умолчанию `5050`), пароль (опционально).
3. Программа покажет локальный IP и порт.

### Подключение

1. Меню **Сетевая игра → Подключиться к игре…**
2. Введите IP хоста, порт, имя, пароль.
3. При потере соединения — **автоматическое переподключение** (до 12 попыток, экспоненциальная задержка).

### Роли

Меню **Сетевая игра → Роли игроков…** (только у хоста):

| Роль | Что может |
|------|-----------|
| **Ведущий** | Роль хоста, не меняется |
| **Игрок** | Отправляет действия |
| **Наблюдатель** | Видит повествование, но не действует |

### Особенности

- **Батчинг ходов** — действия собираются 2.5 секунды и уходят одним запросом.
- **Приватные действия** — галочка «Приватно».
- **Чат игроков** — панель под кнопками, **не уходит в ИИ**.
- **Heartbeat** — ping каждые 15 с, pong-таймаут 45 с.
- **Idle-таймаут** — 5 минут без действий → отключение (кроме наблюдателей).

- ✅ Конфигурация истории

- ✅ Краткое содержание
- ✅ Текст повествования
- ✅ Все карточки
- ✅ Квесты со статусами
- ✅ Карта и текущая локация
- ✅ Важные факты
- ✅ Инвентарь, экипировка, характеристики
- ✅ Свои кнопки
- ✅ Статистика сессии
- ✅ Состояние плагинов

> Запись **атомарная**: сначала во временный файл, потом `os.replace()`. Даже при выключении посреди сохранения старый файл останется целым.

## Плагины

Положите `.py`-файл в `~/.quest_ai/mods/` — он загрузится при запуске или по команде **Плагины → Перезагрузить плагины**.

### Структура плагина

```python
PLUGIN_NAME = "Мой плагин"

def register(api):
    api.register_tag("WEATHER", handle_weather)
    api.register_prompt_hook(build_weather_prompt)
    api.register_turn_end_hook(on_turn_end)
    api.register_provider("my_provider", {...}, my_handler)

def handle_weather(raw, ctx):
    return {"condition": raw.strip()}

def build_weather_prompt(ctx):
    weather = ctx["api"].state.get("weather", {})
    return f"Сейчас в мире {weather.get('condition', 'ясно')}."

def on_turn_end(ctx):
    state = ctx["api"].state
    state.setdefault("counter", 0)
    state["counter"] += 1
```

### Что доступно в `ctx`

| Ключ | Содержимое |
|------|-----------|
| `turn_count` | Номер хода |
| `current_location` | Текущая локация героя |
| `player_name` | Имя героя |
| `player_stats` | Эффективные характеристики |
| `inventory_names` | Имена предметов в рюкзаке |
| `quests_active` | Список активных квестов |
| `plugin_data` | Данные из тегов этого хода |
| `api` | Объект `PluginAPI` |

### Примеры использования

- Погодная система
- Репутация фракций
- Крафт предметов
- Кастомные проверки
- Интеграция с внешним API

## Карточки предметов и существ

ИИ присылает карточки автоматически:

```json
[CARD]
{
  "type": "предмет",
  "name": "Клинок Забвения",
  "description": "Тонкий меч с чёрным лезвием.",
  "properties": {"урон": "+5", "сила": "+2"},
  "equip_slot": "weapon"
}
[/CARD]
```

### Поля карточки

| Поле | Описание |
|------|----------|
| `name` | Обязательное, уникальный ключ (обновляет, а не дублирует) |
| `type` | `предмет` или `существо` |
| `description` | Краткое описание |
| `properties` | Словарь свойств. Если ключ содержит имя характеристики — бонус учитывается в RPG |
| `equip_slot` | `head`, `amulet`, `body`, `hands`, `legs`, `feet`, `belt`, `weapon`, `shield`, `ring` |
| `status` | `жив`, `мёртв`, `потерян`, `уничтожен`, `неизвестно` |
| `attitude` | `союзник`, `нейтрал`, `враг`, `неизвестно` |
| `hp` | Число здоровья для существ |
| `location` | Название локации |
| `character` | 1-2 предложения о характере NPC |
| `goal` | Чего NPC хочет |

### Использование

Меню **Карточки** → вкладки **Предметы**, **Бестиарий**, **Локации**, **Все**. Кнопки: «В рюкзак», «Изменить статус…», «Удалить», экспорт в Markdown/JSON.

## Квесты

ИИ присылает блок:

```
[QUEST]Найти кузнеца|Разыскать в деревне|active[/QUEST]
```

### Статусы

| Статус | Значение |
|--------|----------|
| `active` | В работе |
| `done` | Выполнен |
| `failed` | Провален |

При завершении ИИ присылает квест с тем же именем и новым статусом — запись обновится.

Меню **Квесты** → вкладки **Активные**, **Выполненные**, **Проваленные**, **Все**. Экспорт в Markdown/JSON.

## Важные факты

Список того, что **должно оставаться неизменным** в сюжете. Считается каноном и попадает в промпт перед каждым ходом.

Примеры:

- «Главный герой — эльф по имени Аэлит, ему 250 лет».
- «Королевство Валдор пало три года назад».
- «Меч Клинок Забвения нельзя уничтожить обычным огнём».

Меню **История → Важные факты…**. Кнопки: **+ Добавить**, **Изменить**, **Удалить**, **Вверх**, **Вниз**, **Сохранить**.

> В мультиплеере хост разошлёт факты клиентам.

Все проблемы пишутся в:


Формат: трейсбек, последний промпт, ответ (первые 1500 символов каждого).

## Решение проблем

### Программа не запускается

- Проверьте Python: `python --version`.
- Запустите из терминала: `python quest_ai.py` — увидите ошибку.
- Смотрите `~/.quest_ai/logs/errors.log`.

### «Не найден ключ GigaChat»

- Введите ключ в настройках истории.
- Либо задайте переменные окружения: `GIGACHAT_AUTH_KEY`, `GIGACHAT_CLIENT_ID` + `GIGACHAT_CLIENT_SECRET`.
- Установите библиотеку: `pip install gigachat`.

### «Ошибка сети при обращении к Ollama»

- Проверьте, что Ollama запущена: `ollama serve`.
- Убедитесь, что модель скачана: `ollama pull llama3.1`.
- Base URL: `http://localhost:11434/v1`.

### ИИ не отвечает

- Смотрите статус-строку.
- Проверьте интернет.
- Если в пуле несколько ключей — кончился лимит, программа должна переключиться автоматически.
- `errors.log`.

### Озвучка не работает

- `pip install pyttsx3`.
- На Linux: `sudo apt install espeak`.
- Проверка голосов:

  ```bash
  python -c "import pyttsx3; e=pyttsx3.init(); print(e.getProperty('voices'))"
  ```

### Голосовой ввод не работает

- `pip install SpeechRecognition pyaudio`.
- На Linux: `sudo apt install portaudio19-dev python3-pyaudio`, затем `pip install pyaudio`.
- Нужен интернет (Google Speech API).
- Проверьте микрофон.

### Экспорт PDF падает

- `pip install reportlab`.

### Мультиплеер: клиент не подключается

- Хост запустил сервер?
- IP правильный? (локальный `192.168.x.x` или внешний).
- Порт `5050` открыт в брандмауэре?
- Пароль правильный?

### Установщик не запускается

- Windows SmartScreen: «Подробнее» → «Выполнить в любом случае».
- Некоторые антивирусы ругаются на неподписанные PyInstaller-сборки — добавьте в исключения.
- Запустите от имени администратора.

### Программа не видит сохранения

- Проверьте `C:\Users\Ваше_Имя\.quest_ai\saves\`.
- Меню **История → Недавние сохранения** или **Открыть папку сохранений**.

## Безопасность

- 🔒 **Никогда** не публикуйте `~/.quest_ai/app_settings.json` — там могут быть API-ключи в открытом виде.
- 📁 **Не загружайте** сейвы из ненадёжных источников. Парсер защищён от JSON-bomb (64 КБ, глубина 8), но лучше не рисковать.
- 🌐 **Не подключайтесь** к неизвестным серверам мультиплеера. Хост видит все ваши действия.
- 🧩 **Не запускайте** плагины из ненадёжных источников — это Python-код с полными правами.
- ⚠️ GigaChat использует `verify_ssl_certs=False` (требование SDK). Не работайте через публичный Wi-Fi.

## FAQ

**Можно ли играть без интернета?**
Да, с Ollama. ИИ крутится локально.

**Сколько стоит?**
Программа бесплатная. Платите только провайдеру ИИ. GigaChat Freemium и Ollama — бесплатно.

**Можно ли экспортировать историю?**
Да, в Markdown или PDF.

**Можно ли продолжать после закрытия?**
Да, автосохранение каждые 5 ходов.

**Что если ключ утечёт?**
Отзовите у провайдера, выпустите новый. Храните только в `keyring`.

**Поддерживается ли macOS и Linux?**
Да, из исходников.

**Есть ли мобильная версия?**
Нет. Tkinter не работает на Android/iOS. Нужен Kivy или Flet.

**Как сжать историю?**
Автоматически: при 20 записях первые 10 отправляются ИИ на сжатие.

**Можно ли поменять провайдера посреди игры?**
Да, «Настроить историю…». История, карточки и квесты сохранятся.

**Что если ИИ противоречит сам себе?**
Добавьте правду в «Важные факты».

**Можно ли играть за нескольких персонажей?**
Да, в мультиплеере. Каждый — свой персонаж.

**Как назначить роль наблюдателя?**
Хост: «Сетевая игра → Роли игроков…».

**Почему в отчёте PyCharm 147 «typo»?**
SpellChecker не знает русской IT-лексики (гейммастер, промпт, эндпоинт, батчинг). Ложные срабатывания.
